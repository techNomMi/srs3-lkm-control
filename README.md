## Запустить практическую часть на Python

Требуется Python 3.11 или новее и NumPy:

```text
python -m pip install -r requirements.txt
python train_model.py
python -m unittest -v test_model.py
```

Скрипт заново создаёт `dataset.csv`, `test_predictions.csv`, `control_comparison.csv`, `report.json` и `data.js`. При обновлении страницы сайт покажет новые результаты. Установка зависимостей требует интернета; сами расчёты работают локально.

Практика реализована на Python, а не имитирована в JavaScript. Сайт отображает экспорт Python; интерактивный прогноз использует те же обученные коэффициенты в браузере. Обучение при изменении полей не запускается.

## Данные и алгоритмы

Seed 20261102. 800 строк, 100 партий по 8 наблюдений. Обучение: 80 партий / 640 строк, тест: 20 партий / 160 строк. Партии разделены целиком, чтобы не смешивать связанные наблюдения. Для управления с seed 20261103 создан отдельный набор 30 парных сценариев.

Линейная регрессия по T, n, t, C. Стандартизация оценивается только на обучении; решение МНК — `numpy.linalg.lstsq`. Метрики MAE, RMSE, R² вычислены самостоятельно и проверены тестами. Прогноз среднего обучающей выборки служит базовым сравнением.

Тепловой баланс интегрируется явным Эйлером с шагом 0,25 мин, мощности переводятся в Вт, минуты — в секунды. Энергия рассчитана в кВт·ч. Для переменной скорости однородность считается по накопленному числу оборотов. Коэффициенты и генератор приведены на сайте и в Python-коде.

Традиционный регулятор: n=300 об/мин, нагреватель поддерживает T=35 °C. Прогнозный регулятор перебирает 20 комбинаций скорости/нагревателя с горизонтом до 3 мин и применяет выбранную комбинацию на один шаг. Все ограничения и условия остановки одинаковы. Качество оценивается по модельному датчику вязкости, не только по обученному прогнозу. Веса регулятора условные; это учебная имитация, не промышленная MPC.

Отчёт сравнивает энергию всех партий, время только успешных партий, долю годных и температурное отклонение. Парная экономия считается только для сценариев, где оба подхода дали готовый продукт. Синтетический генератор близок к линейному, поэтому высокая точность на его данных ожидаема и не переносится автоматически на реальное сырьё.

Выбран разрешённый в итоговом задании вариант Python с сравнением управления. Файл MATLAB/Simulink не создавался; структурная схема представлена в веб-отчёте.
